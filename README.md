# WebApp

Prosta aplikacja Flask z logowaniem i panelem administratora.

## Wymagania

- Python 3.10+
- Wirtualne środowisko (opcjonalnie)

## Instalacja

```bash
pip install -r requirements.txt
```

## Uruchomienie

```bash
python app.py
```

Aplikacja będzie dostępna pod adresem `http://127.0.0.1:5000/`.

### Dane logowania

- Login: `zaba`
- Hasło: `pass`

Po zalogowaniu przejdź do panelu administratora, gdzie możesz zmienić dane logowania.
